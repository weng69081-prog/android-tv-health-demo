查询接口清单

零依赖 Python 服务 · server.py
接口说明参数返回
GET /api/summary总览指标—总开机、崩溃数、崩溃率、开机异常率、健康度、P50/P95
GET /api/kpi版本级 KPI—3 个版本的崩溃率、开机异常率、健康度（按铁律复算）
GET /api/trend按周崩溃趋势—周列表 + 每版本的崩溃数序列
GET /api/devices崩溃设备排行limit设备 ID + 崩溃次数
GET /api/detail明细查询（可追溯）version / status / device / limit / offset分页明细 + 总数
GET /api/attr崩溃归因—按错误类型 / 应用分组的次数与占比

怎么启动

面试现场可跑
# 1. 启动查询服务（无第三方依赖）
python server.py
# → 查询服务已启动：http://127.0.0.1:8010  (数据 1000 条)

# 2. 跑压测，复现上面的数字
python bench.py
# → P95 / 成功率 / 5 并发 三项对照验收指标

演示版页面默认使用静态数据（merge.js），保证任何环境打开都能看； 接口版使用同一份数据源（mock_log_data.csv），前端只需把数据来源换成 fetch('/api/kpi') 即可切换，页面结构不用改。
