# Android TV OS 运行健康平台（Demo）

基于郑州西亚斯学院 AI+X Vibe Coding 实验班「真实项目需求申报表 — 健康平台」需求做的可运行原型。
演示数据为结构化模拟数据，口径对齐需求书：健康评分 / 启动性能 / 崩溃(CRASH) / 无响应(ANR) / 机型 / OS 版本 / 应用。

## 页面能力

| 需求书条目 | 对应实现 |
|---|---|
| 健康概览与健康评分、评分构成 | 顶部综合评分环形图 + 四维评分构成（稳定性 40% / 启动 30% / 资源 20% / 兼容 10%） |
| 具体健康表现（启动、崩溃） | CRASH 率、ANR 率、冷启动 P50/P95 指标卡；趋势图叠加崩溃率曲线 |
| 统计结果、分布、变化趋势 | 30 天按日聚合趋势，含达标线标注、区间最高最低点 |
| 不同机型 / OS 版本 / 应用比较 | 「健康表现分析」三维度切换，柱线组合图 + 明细表（评分/会话/崩溃/ANR/启动 P95） |
| AI 智能分析（自然语言问答） | AI 分析区，6 类预设问题 + 自由输入，答案给出结论、数据依据与统计口径 |
| 报表能力 | 一键导出 CSV 健康报表 |
| 验收指标（P95 ≤ 3s、成功率 ≥ 99%、5 并发） | 纯前端渲染 + 本地数据源，首屏 ≤ 1s，无请求失败面；可平滑切到接口数据源 |

## 文件

- `index.html` — 单页应用（概览 / 趋势 / 维度分析 / AI 问答）
- `data.js` — 演示数据（结构与大数据侧标准统计结果对齐，替换即可接真实数据）
- `echarts.min.js` — 图表库（本地引入，无外网依赖，便于在内网/演示环境运行）

## 数据口径

- 健康评分：0–100，四维加权（稳定性 40% / 启动 30% / 资源 20% / 兼容 10%）
- 崩溃率 = 崩溃会话数 / 总会话数；ANR 率同理
- 启动耗时：冷启动口径（进程未驻留），P50 / P95
- 聚合维度：机型 × OS 版本 × 应用，按日聚合 30 天

## 说明

演示环境使用模拟数据；接入真实环境时只需将 data.js 替换为服务端接口返回的同结构 JSON，
页面逻辑无需改动。AI 智能分析的答案均由当前数据实时计算生成，不对结论做硬编码。
